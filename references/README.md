# Handyman References

Progressive-loading references for the `handyman` skill. Read only the file needed for the current mode:

- `anatomy.md` - structure, file responsibilities, Obsidian frontmatter conventions.
- `workflow.md` - leader, implementer, reviewer, and closure protocols.
- `templates.md` - starter files for bootstrap (including Obsidian MOC and `.gitignore`).
- `examples.md` - end-to-end bootstrap and run-feature walkthroughs.
- `checklists.md` - analysis, bootstrap, run, review, Obsidian, and risk checks.
- `models.md` - per-role model assignment, defaults, editor model discovery.
- `tools.md` - per-role tool restrictions, capability groups, per-platform syntax.
- `obsidian.md` - vault setup, plugins, frontmatter, tags, wikilinks.
- `graphify.md` - knowledge-graph context layer: install, freshness, role queries.
