# Foreman References

This directory contains progressive-loading references for the global `foreman` skill. The references cover both local installs, where all harness files live in the project root, and global FOREMAN installs, where mutable state lives under `$HOME/FOREMAN/<project_name>`.

Read only the file needed for the current mode:

- `anatomy.md` for structure and file responsibilities.
- `workflow.md` for leader, implementer, reviewer, and closure protocols.
- `templates.md` for starter files when bootstrapping a repo.
- `checklists.md` for analysis, bootstrap, run, review, and risk checks.
